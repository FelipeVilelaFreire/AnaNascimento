# AnaNascimento

Landing page da Ana Nascimento Advocacia, organizada como laboratorio local para evoluir o uso do ServiceOS em novas aplicacoes.

## Estrutura

- `frontend/landingpage`: aplicacao Next.js da landing.
- `docs`: documentacao do projeto e feedbacks do laboratorio ServiceOS.
- `bats`: atalhos Windows para setup, dev e build.

## Comandos

Use os scripts em `bats/` ou rode os comandos dentro de `frontend/landingpage`.
