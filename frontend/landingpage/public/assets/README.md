# Assets

Arquivos publicos servidos pelo Next.

Use caminhos iniciando por `/assets/...` dentro do conteudo da landing.

Exemplo:

```js
assets: {
  heroImage: "/assets/images/hero.jpg",
  portraitImage: "/assets/images/ana-nascimento.jpg",
}
```

## Organizacao

```text
assets/
  images/   fotos, logos e imagens editoriais da landing
```
